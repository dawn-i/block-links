# Who dat link?

This Obsidian plugin shows a small `↩ N` badge on linked headings and blocks. Click the badge to interact with a list of the incoming links. A `Rename` button renames the destination and keeps the links connected.

Features
- Block and heading link badges with counts.
- Popover with incoming links list.
- Convenient renaming.

Problems addressed
- Renaming headings and block IDs in the editor breaks links.
- Searching to identify or back-follow the links takes me out of flow.
- Running rename commands from the palette or context menu can be tedious.

Status: Fully functional. The alpha testing cohort of one reports two thumbs up. Polish and more features to come, spare time permitting.

How to get this plugin into your Obsidian vault: Install the [BRAT community plugin](https://community.obsidian.md/plugins/obsidian42-brat), and give it the link to this GitHub repository. Should I find time to solicit and respond to testers, I might put this one in the community directory.
